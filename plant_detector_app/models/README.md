# Thư mục lưu trữ Model AI (YOLO)

Vui lòng đặt file model huấn luyện của bạn vào thư mục này với tên:
```
best.pt
```

Đường dẫn đầy đủ:
```
plant_detector_app/models/best.pt
```

## Lưu ý:
- File model phải là định dạng PyTorch weights của Ultralytics YOLO (`.pt`).
- Ứng dụng Streamlit sẽ tự động phát hiện và nạp model ngay khi file xuất hiện.
